# Personal portfolio of Godfred Larbi

Live site: [goflarbi.com](https://www.goflarbi.com)

## Editing

- Edit page content and metadata in `index.html`.
- Edit project cards and interactions in `js/main.js`.
- Edit the visual design and responsive layout in `css/styles.css`.
- Replace the profile photograph or CV in `assets/` while retaining their filenames.

Open `index.html` directly or serve the repository with a static web server to preview changes. Push updates to the `main` branch to publish them through the connected hosting services.
